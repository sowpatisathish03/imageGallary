# 🖼️ Image Gallery

A simple, modern, and responsive Image Gallery website built using **HTML, CSS, and JavaScript**.

The project allows users to browse images, filter them by category, search for images, and view them in a full-screen lightbox.

## ✨ Features

* 🖼️ Responsive image gallery
* 🔍 Image search
* 🏷️ Category filtering
* 🔎 Image hover zoom effect
* 💡 Lightbox image preview
* ⬅️ Previous and Next navigation
* ❌ Close lightbox button
* 📱 Mobile-friendly design
* 🎨 Clean and modern user interface
* ⚡ Fast and lightweight frontend

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, Grid, Flexbox and animations
* **JavaScript** – Filtering, search and lightbox functionality

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Run the project using **Live Server** or open `index.html` directly in your browser.
